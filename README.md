# MedBook

MedBook is a full-stack clinic appointment management system built with React, Tailwind CSS, Java, Spring Boot, Spring Data JPA, Hibernate, and MySQL.

## Project Overview

MedBook streamlines clinic operations by providing a comprehensive appointment management system. The platform enables patients to book appointments with healthcare providers and allows clinics to manage their schedules efficiently.

## Planned Technology Stack

### Backend
- **Java 17+** - Core language
- **Spring Boot** - Application framework
- **Spring Data JPA** - ORM and data access
- **Hibernate** - JPA implementation
- **MySQL** - Primary database
- **Maven** - Build tool

### Frontend
- **React 18+** - UI library
- **Tailwind CSS** - Styling
- **Vite** - Build tool and development server
- **Node.js / npm** - Package management

### Development Tools
- **IntelliJ IDEA** - IDE
- **VS Code** - Code editor
- **Git** - Version control

## Planned Modules

### Backend Modules
- User Management (Patients, Doctors, Admins)
- Appointment Management
- Schedule Management
- Notifications

### Frontend Modules
- Authentication & Authorization
- Patient Dashboard
- Doctor Dashboard
- Admin Dashboard
- Appointment Booking Interface
- Schedule Management Interface
